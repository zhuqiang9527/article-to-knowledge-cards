# make-knowledge-cards

把文章变成知识卡片的 Agent Skill：将用户粘贴的文章或本地 Markdown/TXT 文本，提炼成 5\~8 张结构化知识卡片（每张含 **标题 / 核心知识 / 简明解释 / 例子或自测问题**），用于高效学习、记忆与复习。

## 1. 解决什么问题

读长文章、记笔记、备考复习时，信息量大且结构散乱，人很难抓住要点。本项目提供一套明确的规则，让 Agent 把一篇长文自动浓缩成一组**结构化、可自测的知识卡片**：



* 把 "一篇长文" 拆成 "几个独立知识点"，方便逐点学习和记忆

* 每张卡自带 "例子或自测问题"，把被动阅读变成主动检验

* 只提炼原文真实内容，不编造、不注水，保证可靠

## 2. 主要功能



* **文章转知识卡片**：直接粘贴正文，或提供本地 `.md` / `.txt` 文件，输出 5\~8 张卡片

* **每卡固定四字段**：标题、核心知识、简明解释、例子或自测问题

* **一张卡片一个知识点**：严格保证每卡只讲一个独立知识点，不混装

* **自动去重**：同一知识反复出现时合并为一张卡，卡片间不雷同

* **不编造、不凑数**：卡片内容均来自原文；信息不足时宁少勿滥，不为凑满 5 张而注水

* **叙事文本不硬转**：散文、小说等以叙事抒情为主、缺乏事实性知识点的文本，如实告知不适合，不强行 "知识点化"

**支持的输入与不支持的输入**



| 输入                   | 支持 |
| -------------------- | -- |
| 直接粘贴的文章正文            | ✅  |
| 本地 `.md` / `.txt` 文件 | ✅  |
| 网页抓取 / URL           | ❌  |
| PDF / Word / 图片      | ❌  |
| Anki 导入              | ❌  |
| 图形界面输出               | ❌  |

## 3. 安装方法

本项目是一个 Agent Skill（技能包），安装即让 Agent 具备 "文章转知识卡片" 的能力。本机 Agent 的技能目录以 `workspace/.user_skills` 结尾（本环境为 `<你的技能目录>/workspace/.user_skills`）。

**方式一：复制到技能目录（推荐）**

把整个技能文件夹复制到 Agent 的 `workspace/.user_skills` 下：



```
Copy-Item -Recurse -Force "<本机技能源目录>\skills\make-knowledge-cards" `
  "<你的技能目录>\workspace\.user_skills\"
```

（请将目标路径换成你实际环境中的技能目录。）

**方式二：直接用官方工具初始化**（从零重建，一般无需）

本技能由官方 `skill-creator-for-work` 的 `init_skill.py` 初始化生成，如需重建骨架：



```
python init_skill.py make-knowledge-cards --path <你的skills目录>
```

**本技能无需 Python 依赖和脚本**：它是纯文本提炼任务，由 Agent 读取并执行 `SKILL.md` 中的规则即可，无需额外安装包或运行脚本。

**项目结构**



```
<项目根目录>/
├── README.md                        # 本项目说明
├── skills\make-knowledge-cards\     # 技能本体（安装时整体复制此目录）
│   ├── SKILL.md                     # 技能主说明：工作流程与硬性约束
│   └── agents\
│       └── openai.yaml              # OpenAI 兼容 Agent 配置（模型与系统指令）
└── test_articles\                   # 本地测试文章与测试记录
```

## 4. 使用方法

安装完成后，直接对 Agent 说话即可。两种用法：

**用法一：粘贴文章正文**

> 把下面的文章做成知识卡片：
> 血压是血液对血管壁的侧压力。心脏收缩时压力达到最高值，叫收缩压……

**用法二：提供本地文件**

把 `.md` 或 `.txt` 文件交给 Agent，并说明：

> 请把这份《科普 - 睡眠.md》做成知识卡片。

Agent 会按 `SKILL.md` 的流程处理：通读全文 → 提炼候选知识点 → 去重筛选 → 一卡一点 → 控制数量（5\~8 张，不足不凑数）→ 逐卡撰写四字段，并以 Markdown 形式输出。

**使用注意**



* 只接受**纯文本**（粘贴正文 / `.md` / `.txt`）；PDF、Word、图片、URL 不支持，请先转成文本

* 若原文是散文、小说等叙事文本，Agent 会如实告知不适合，而非强行出卡

## 5. 输入输出示例

**输入**（科普短文片段）：

> 血压是血液对血管壁的侧压力。心脏收缩时压力达到最高值，叫收缩压；心脏舒张时降到最低值，叫舒张压。

**输出**：



```
## 卡片 1｜血压是什么
**核心知识**
- 血压是血液对血管壁的侧压力
- 收缩压：心脏收缩时的最高值；舒张压：心脏舒张时的最低值
- 常用写法：收缩压/舒张压，如 120/80 mmHg
**简明解释**
心脏一张一缩，血管里的压力随之高低起伏。收缩一瞬压力最高，舒张时降到最低。
**例子或自测问题**
- 自测：血压 120/80 中，"120"和"80"分别代表什么？
```

**输入**（叙事散文片段）：

> 书店开在镇子东头，门口有一棵老槐树…… 老王说，卖书有时就是卖一个缘分。

**输出**（按边界规则不强行出卡）：

> 该文本为叙事散文，以氛围与情感为主，缺乏可拆解的事实性知识点，不适合 "知识卡片"。如需，我可以改为情节梳理或主题解读。
