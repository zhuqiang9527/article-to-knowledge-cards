# Git 分支管理实战

## 什么是分支
分支是 Git 里一条独立的开发线。默认的分支叫 main（以前叫 master）。你可以在 main 上开一条新分支，在里面做实验，不影响主分支的稳定。

## 创建和切换分支
创建分支用 git branch 分支名；切换到某个分支用 git checkout 分支名，或者用 git switch 分支名。一条命令同时创建并切换，可以用 git checkout -b 新分支名。

## 合并分支
开发完成后，要把新分支的成果并回主分支。先切换到 main，然后执行 git merge 新分支名。如果两个分支改的是不同文件，合并通常很顺利；如果改了同一个文件的同一处地方，就会产生冲突（conflict），需要手动解决。

## 解决冲突
出现冲突时，Git 会在冲突文件里用 <<<<<<<、=======、>>>>>>> 标出两边的内容。你要自己决定保留哪边、怎么合并，改完后 git add 该文件，再提交，冲突就解决了。

## 删除分支
分支合并完，如果不再需要，可以用 git branch -d 分支名删除它。注意：-d 只会在分支已合并时才允许删除，避免误删未合并的工作。

## 一句话总结
分支的作用是让多个开发线互不干扰，开发完再合并，有冲突就手动解决，不需要了再删除。
